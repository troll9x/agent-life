## Các bước thực hiện

1. Khóa toolchain Ktor/Kotlin/JDK ổn định tương thích; ghi version thật vào SERVER.md.
2. Cấu hình env theo profile local/test/production, không commit password/secrets; env example chỉ chứa placeholder.
3. Tạo health/readiness, lỗi JSON chuẩn, request ID và log đã làm sạch.
4. PostgreSQL migration qua Flyway hoặc công cụ đã chọn và khóa; DB local bằng container nếu môi trường có.
5. Có server test runner và lệnh build; không phụ thuộc Android Studio/emulator.

## Kiểm thử và build

Ưu tiên kiểm nhỏ nhất đánh đúng rủi ro. Dưới đây là lệnh dự kiến sau scaffold; kiểm `TOOLCHAIN.md`/`TESTING.md` trong repo để dùng command thật nếu toolchain thay tên task. Không ghi PASS cho command chưa chạy.

```powershell
Set-Location server
.\gradlew.bat test build
```

Nếu sửa UI, chạy smoke test/Compose test và mô tả màn hình thực tế. Nếu sửa Room, chạy migration/instrumentation trên thiết bị khi có. Nếu sửa HTTP, có fixture/mock-server cho lỗi và phân trang; cần gate thật thì theo [thiết lập](../../09_EXTERNAL_SETUP.md). Thiếu môi trường ghi NOT_RUN/EXTERNAL_BLOCKED và lý do cụ thể.
