## Các bước thực hiện

1. Cho chọn calendar ID từ metadata, đọc calendarView trong cửa sổ hữu hạn và theo phân trang/delta hợp lệ.
2. Map all-day, timezone, occurrences, cancellation, organizer, webLink và online meeting URL vào calendar cache riêng theo source.
3. Dùng source identity thay tiêu đề để chống trùng; liên kết invite email với event ID/iCalUID khi có, không xóa hai event vì cùng title.
4. Đổi/sửa remote event cập nhật cache; event remote hiện badge Microsoft và editor chỉ đọc.
5. Không có quyền calendar thì source unavailable; bản tin không được khẳng định lịch trống.

## Kiểm thử và build

Ưu tiên kiểm nhỏ nhất đánh đúng rủi ro. Dưới đây là lệnh dự kiến sau scaffold; kiểm `TOOLCHAIN.md`/`TESTING.md` trong repo để dùng command thật nếu toolchain thay tên task. Không ghi PASS cho command chưa chạy.

```powershell
Set-Location android
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

Nếu sửa UI, chạy smoke test/Compose test và mô tả màn hình thực tế. Nếu sửa Room, chạy migration/instrumentation trên thiết bị khi có. Nếu sửa HTTP, có fixture/mock-server cho lỗi và phân trang; cần gate thật thì theo [thiết lập](../../09_EXTERNAL_SETUP.md). Thiếu môi trường ghi NOT_RUN/EXTERNAL_BLOCKED và lý do cụ thể.
