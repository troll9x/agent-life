## Các bước thực hiện

1. Thêm sync_change, processed_event và aggregate version với unique(workspaceId,eventId).
2. Authenticate membership từ token/session server; không lấy workspace quyền từ JSON client.
3. Trong transaction: check baseVersion, ghi data/change và ACK, duplicate trả ACK cũ.
4. Pull filter workspace theo quyền, cursor scoped workspace/user; giới hạn batch và giữ ordering ổn định.
5. Ledger transaction header+entries là một aggregate, không nhận từng entry thiếu đối ứng.

## Kiểm thử và build

Ưu tiên kiểm nhỏ nhất đánh đúng rủi ro. Dưới đây là lệnh dự kiến sau scaffold; kiểm `TOOLCHAIN.md`/`TESTING.md` trong repo để dùng command thật nếu toolchain thay tên task. Không ghi PASS cho command chưa chạy.

```powershell
Set-Location server
.\gradlew.bat test
```

Nếu sửa UI, chạy smoke test/Compose test và mô tả màn hình thực tế. Nếu sửa Room, chạy migration/instrumentation trên thiết bị khi có. Nếu sửa HTTP, có fixture/mock-server cho lỗi và phân trang; cần gate thật thì theo [thiết lập](../../09_EXTERNAL_SETUP.md). Thiếu môi trường ghi NOT_RUN/EXTERNAL_BLOCKED và lý do cụ thể.
